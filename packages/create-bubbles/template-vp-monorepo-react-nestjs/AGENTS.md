## 目录说明

## 按需规则

根据当前任务匹配下表，在执行相关操作前读取对应规则；命中多项时分别读取。不要预先加载整个 `.agents/rules/` 目录；任务范围变化时补读新命中的规则。

| 适用条件                                                       | 规则文件                              |
| -------------------------------------------------------------- | ------------------------------------- |
| 新增、修改或重构前后端代码                                     | [代码设计](.agents/rules/代码设计.md) |
| 定义或调整前后端接口类型、返回类型，或新增、修改、抽取公用方法 | [共享代码](.agents/rules/共享代码.md) |
