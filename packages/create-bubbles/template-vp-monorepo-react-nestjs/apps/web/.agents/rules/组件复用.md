# 组件复用与静态内容

- 开始新增或修改页面、布局或 React 组件前，先检查是否已有可复用组件，并识别页面结构中可复用的展示或交互，再根据全部引用方的实际范围确定组件归属。
- 供整个前端应用复用的组件统一放在 `@/components`。该目录优先放置跨页面、低业务耦合且接口稳定的通用组件。
- 只在局部范围复用的组件放在所有引用方最近公共祖先目录下的 `components` 中。组件新增了该目录之外的引用方时，须重新计算最近公共祖先，将组件移动到新公共范围对应的 `components`，并同步更新引用；复用范围扩展到整个应用时，移动到 `@/components`。
- 不依赖父组件本次渲染局部值的静态常量、配置和 JSX 放在 React 组件函数外。小且仅属于当前页面的内容可放在同一文件的模块顶层；较多配置抽离到当前功能目录的 `config/index.ts`、`config/index.tsx` 或其他职责明确的配置文件；具有独立 UI 职责或适合复用的内容抽成 `components/<ComponentName>`。
- 在 React 组件函数内声明的子组件须移到函数外或相应的 `components` 目录；需要父组件的数据或回调时，通过 props 显式传入。
