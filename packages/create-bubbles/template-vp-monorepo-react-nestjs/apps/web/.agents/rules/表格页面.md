# 表格页面

适用于以表格为主体，包含查询、新增、编辑、删除等操作的列表页面。

- 普通表格类增删改查页面统一使用 [FullHeightProTable](../../src/components/FullHeightProTable/FullHeightProTable.tsx)。包含草稿或草稿箱功能时统一使用 [DraftProTable](../../src/components/DraftProTable/DraftProTable.tsx)，使用前阅读其 [组件说明](../../src/components/DraftProTable/README.md)。业务页面复用现有封装，不直接使用原生 `ProTable` 重复实现同类布局和草稿入口。
- 沿用组件的固定表头、表体独立滚动、分页贴底布局。父容器需有明确高度，位于 flex 布局时按需设置 `min-h-0`；组件内部已包含 `w-full h-full p-[16px]`，页面不要重复添加同一层间距或改成整个表格外层滚动。
- `columns`、`request`、`params`、`actionRef`、`pagination`、`toolBarRender` 等沿用 ProTable 参数，并保留行数据和查询参数的类型。查询、新增、编辑、删除、表单及权限等业务逻辑由页面负责，不放进通用表格组件。
- 使用 `DraftProTable` 时，由页面受控维护 `view: 'list' | 'draft'`，默认显示 `list`，通过 `onViewChange` 切换。草稿箱入口放在刷新、列设置旁，点击选中并显示草稿，再次点击取消选中、返回列表。
- 通过 `draftCount` 传入草稿总数，使用组件自带的右上角数字角标；0 条或未传入时隐藏，超过 99 显示 `99+`，不使用 Tooltip 展示数量。
- 使用 `request` 时，通过 `params` 传递当前列表或草稿视图对应的查询条件。切换视图时由页面重置分页和行选择，并按业务需要重置筛选条件。草稿保存、继续编辑、提交、数据刷新和数量更新由页面及其接口处理。
- 基础用法参考 [基础示例](../../src/pages/examples/pro-table/index.tsx)，草稿用法参考 [草稿示例](../../src/pages/examples/pro-table/draft/index.tsx)。示例中的本地存储和固定演示用户仅用于 Demo，实际业务按项目接口和权限规则接入。
