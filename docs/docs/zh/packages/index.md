# 工具包总览

选择一个工具包，查看它的安装方式、使用示例和 API。接口说明统一放在各包页面中。

| 工具包                                                          | 说明                                                          |
| --------------------------------------------------------------- | ------------------------------------------------------------- |
| [@bubblesjs/request](/packages/request)                         | 基于 Alova 的请求封装，支持响应处理、错误处理和双重调用模式。 |
| [@bubblesjs/utils](/packages/utils)                             | 对象合并、类型判断与 JSON 解析等工具函数。                    |
| [@bubblesjs/vue-ai-chart](/packages/vue-ai-chart)               | Vue 3 AI 聊天组件，支持会话管理、Markdown 和代码高亮。        |
| [@bubblesjs/vue-annotation](/packages/vue-annotator)            | Vue 3 文本标注组件，支持实体、关系标注和 Unicode 字素处理。   |
| [@bubblesjs/vue-infinite-scroll](/packages/vue-infinite-scroll) | Vue 3 无缝自动滚动组件，支持悬停暂停和速度配置。              |

需要创建新项目？前往 [create-bubbles 模板总览](/templates/) 选择框架与工具链，或从 [快速开始](/guide/start/quick-start) 创建项目。
