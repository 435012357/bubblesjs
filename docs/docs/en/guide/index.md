# Guide

Use `create-bubbles` to create Vue, React, Taro, Next.js, or full-stack projects, or launch the Electron scaffolder for a desktop app.

- [Quick start](/en/guide/start/quick-start): prepare your environment, create a project, and start development.
- [Template overview](/en/templates/): compare templates and find their setup, development, and build commands.
- [Packages](/en/packages/): add request utilities, helper functions, and Vue components to an existing project, with installation, examples, and API references on each package page.
